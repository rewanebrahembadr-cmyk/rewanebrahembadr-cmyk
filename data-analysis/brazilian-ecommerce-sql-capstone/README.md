# Brazilian E-Commerce Analysis — SQL Capstone Project

A team data-analysis capstone project focused on **e-commerce operations and customer experience** using the Brazilian Olist dataset.

## Project Goal

Turn relational e-commerce data into business insights across sales, customers, sellers, payments, delivery performance, and logistics.

## Tech Stack

- SQL
- SQLite
- Python
- Pandas
- Google Colab
- Matplotlib

## Analysis Scope

The project is organized into 12 analytical tasks:

1. Data Quality & Key Audit
2. Executive KPI Layer
3. Monthly Business Trends
4. Category Performance
5. Payment Behavior
6. Seller Performance
7. Delivery SLA Analysis
8. Customer Experience
9. Repeat-Customer Analysis
10. Freight Efficiency
11. Window-Function Ranking
12. Reusable Analytics View

## Key Analytical Themes

- Revenue and order trends
- Product-category performance
- Payment behavior
- Seller performance
- Delivery delays and SLA performance
- Relationship between delivery and review scores
- Repeat-customer behavior
- Freight efficiency by state, category, and seller
- SQL window functions for ranking
- Reusable order-level analytical views

## Team Project

Completed by a **4-member team** as a collaborative SQL capstone project.
